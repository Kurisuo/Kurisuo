### Featured Projects

**[SlugOS](https://github.com/Kurisuo)** *(In Progress)* — `C++` `Limine` `QEMU` `x86_64`  
From-scratch operating system targeting bare-metal memory management, preemptive multithreading, Ring 3 user isolation, and a minimalist serial/framebuffer shell.

**[Multi-Threaded HTTP Server](https://github.com/Kurisuo/multithreaded-http-server)** — `C` `POSIX`  
Sustains **8,400 req/s** at 64 concurrent connections (**~13 ms p99** on a 6-core VM). Achieved a **2.2x speedup** using a fixed thread pool, bounded producer-consumer queue, per-URI reader-writer locks, and audit logging.

**[VeriFi](https://github.com/Kurisuo/VeriFi)** — `C++17` `nlohmann/JSON`  
Founded and led a 5-person team building a policy-grounded RAG engine. Implemented a custom C++ top-*k* cosine-similarity search engine running in **0.36 ms** (1k passages), scaling linearly to **96 ms** (250k passages) at **33k chunks/sec** ingestion.
